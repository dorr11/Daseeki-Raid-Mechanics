# Daseeki Raid Mechanics

Per-raid, per-fight boss mechanic alerts for WoW Classic Era — DBM-lite timer bars, center warnings, and sounds, scoped to specific mechanics rather than full encounter timers.

## Features

- Timer bars and center-screen warnings per mechanic (`alerts.lua`, `engine.lua`).
- Configurable placement and sound per mechanic (`options.lua`, `soundpicker.lua`).
- Naxxramas coverage: Loatheb, Four Horsemen, Gothik, Razuvious, Maexxna, Thaddius (`data_naxxramas.lua`, `mod_*.lua`).
- Bundled sound packs under `Sounds/DBM-Core` (see Licensing).

## Requires

- Optional: [Daseeki Core](../Daseeki-Core) — adds the options panel to the shared Daseeki options hub.
